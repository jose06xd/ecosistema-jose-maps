# Mapas offline de Ecosistema José

Este repositorio público distribuye exclusivamente mapas offline e índices de búsqueda para la App Científica. No contiene código de la aplicación ni datos científicos personales.

`manifest.json` es el catálogo versionado: indica cobertura, versiones, tamaños, SHA-256 y URLs de cada paquete. Los archivos grandes (`.pmtiles` y `.search.sqlite`) se publican como assets de GitHub Releases, nunca en el historial Git.

El primer paquete cubre Bocas del Toro. Cartografía basada en OpenStreetMap/Geofabrik; las atribuciones completas acompañan el mapa y el manifest.
